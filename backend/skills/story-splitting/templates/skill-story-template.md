## 使用说明（给 story-splitting Skill 用，非卡正文）

### 与 `story-template.md` 的差异

| 维度 | `story-template.md`（Java 功能） | `skill-story-template.md`（Skill） |
|------|----------------------------------|-------------------------------------|
| 产出物 | Java 代码 + 测试 | SKILL.md + 配套指引/模板 |
| 验证方式 | TDD（JUnit）+ 黑盒 pytest | 试点 + AC 对照 |
| 必备章节 | AC / BR / 依赖 / 测试关注点 | + §2.4 边界场景清单 + §2.5 交互矩阵 |
| 跳过 | — | OpenAPI / schema / Java 骨架 / TS |
| 影响层 | BFF / API / Service / Domain / Mapper | 方法论 / 工程 |
| 章节编号 | §1-§8 | §1-§8（与同族对齐） |

### 流水线裁剪建议

```text
1. story-splitting（用本模板）→ 产出 Skill Story 卡
2. 轻量详设 → 步骤分解 + 边界场景 + 交互矩阵（不要 OpenAPI/schema/骨架）
3. 直接写 SKILL.md（不走 feature-coding）
4. 试点验证 → 拿 1-2 个真实场景跑一遍
5. 对照 AC 迭代 → 试点暴露的缺陷回头补详设
```

### 何时用本模板

- 新建 `skills/{name}/SKILL.md`
- 重写 / 大改现有 Skill（小改直接改 SKILL.md，不必走 Story）
- Skill 配套资产（template/guide/conventions）首次落地

### 何时不用本模板

- Java 业务功能 → 用 `story-template.md`
- 跨服务重构 → 另开 Story
- Skill 小修小补（改文案、补示例）→ 直接改 SKILL.md
