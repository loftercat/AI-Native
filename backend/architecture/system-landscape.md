## 三、架构与分层规范

### 3.1 架构约束

逐条列出硬约束：微服务独立部署、API 网关 + BFF + 领域微服务分层、数据归属隔离、内部接口防外泄底线。Rule（`rules/`）是权威来源时本节只给概览并指过去。

| 约束 | 说明 |
|------|------|
| 服务独立 | 每个 BFF 与领域微服务独立启动、独立打包、独立数据源 |
| 对外入口 | 对外 HTTP 仅由网关路由至 BFF；领域服务只暴露内部远程接口（具体协议见 §5.4 P-2） |
| 数据隔离 | 每服务独立 DB 与迁移脚本；严禁跨服务 JOIN、跨服务外键与跨域本地 `@Transactional` |
| 内部安全 | 严禁依赖进程内不可达假设；严禁直信来自公网的身份/内部请求头（具体方案见 §5.4 P-5） |

### 3.2 模块与包结构

包结构概览（权威来源为 `rules/java-project.md` 与 `rules/project-layout.md`）。写清：网关/BFF/领域服务（`*-api` + `*-impl`）的目录职责、`*-impl` 内部分层（接口入口/facade/service/client/infrastructure 等）、包名约定。

### 3.3 命名规范

| 类型 | 命名 | 示例 | 所在位置 |
