# 概设 vs 详设边界指引

> 配套 `high-level-design` 与 `detail-design` Skill。冲突时：概设定边界与规则，详设定可编码契约。

## 1. 一句话

| | 概设（HLD） | 详设（DD） |
|---|------------|-----------|
| **粒度** | Epic / 能力域 | 单张 Story |
| **核心问题** | 拆什么、谁拥有什么、怎么连 | 这张 Story 怎么实现、AC 怎么验 |

---

## 2. 分维度对比（必填四维度）

### 2.1 接口设计

| 对比项 | 概设（HLD） | 详设（DD） |
|--------|-------------|------------|
| **目的** | 集成拓扑与契约面 | 可编码、可测的契约体 |
| **REST** | 资源名 + 主要操作骨架 | 完整 path、query、header、版本 |
| **请求/响应** | 核心实体名 + 3～5 个关键字段 | 全字段、类型、必填、枚举 |
| **错误** | 错误分类原则 | HTTP 状态码 + 业务码 + 文案 |
| **幂等/重试** | 写操作须幂等（原则） | 幂等键字段、存储、过期 |
| **文档形态** | 集成矩阵 + API 清单表 | OpenAPI YAML + AC 映射表 |

### 2.2 流程图 / 时序图

| 对比项 | 概设（HLD） | 详设（DD） |
|--------|-------------|------------|
| **数量** | 少量主旅程（3～7） | 每 Story 1～2 张（按需） |
| **泳道** | 系统级或微服务级 | Controller/Service/DB/MQ |
| **分支** | 主路径 + 关键异常 | AC 的 Given/When/Then |
| **用途** | 对齐边界、发现缺失服务 | 指导编码与集成测试 |

### 2.3 领域模型

| 对比项 | 概设（HLD） | 详设（DD） |
|--------|-------------|------------|
| **范围** | 跨系统核心概念与归属 | 单服务 Story 相关对象 |
| **深度** | 概念定义、上下文映射 | 聚合根、不变量、状态机 |
| **类图** | Context Map（可选） | 可实现类图 |
| **与表** | 不绑表结构 | §4 领域 + §6 持久化分离 |

### 2.4 数据持久化

| 对比项 | 概设（HLD） | 详设（DD） |
|--------|-------------|------------|
| **数据主权** | 哪服务唯一拥有写权限 | 消费，不重新分配 |
| **逻辑模型** | 跨服务实体关系 | 本服务表、索引、分库键 |
| **一致性** | Saga / 最终一致（模式） | 本地事务、补偿步骤 |
| **DDL** | 不写 | 写 schema 或等价说明 |

---

## 3. 扩展维度（可选，非阻断）

### 3.1 消息 / 事件

| 概设 | 详设 |
|------|------|
| Topic 名、事件类型、生产者/消费者 | 完整 Payload Schema、消费幂等实现 |

### 3.2 NFR

| 概设 | 详设 |
|------|------|
| SLA、容量数量级、安全分区 | 超时、连接池、熔断阈值、配置项 |

### 3.3 安全

| 概设 | 详设 |
|------|------|
| 信任边界、鉴权模型（OAuth/内部 Token） | 接口权限码、字段脱敏 |

### 3.4 ADR

| 概设 | 详设 |
|------|------|
| 拆服务、选 MQ、一致性模型 | 局部实现选型（如分布式锁实现） |

---

## 4. 判定口诀

| 问题 | 放概设 | 放详设 |
|------|--------|--------|
| 换一个 Story 还要不要？ | 要 | 不要 |
| 不涉及字段/类名能说清吗？ | 能 | 不能 |
| 影响多个团队/服务？ | 是 | 否 |
| 测试要据此写用例？ | 原则 | 用例级 |

---

## 5. 交接物

```text
HLD ──────────────────────────────► DD
  • 服务边界图                    读取，不推翻
  • 集成矩阵                      展开为本 Story 涉及的行
  • 粗 API 清单                   展开为 OpenAPI operation
  • 数据主权表                    展开为表/实体设计
  • 建议 Story 列表               story-splitting 输入（非 Story 正文）
```

详设发现概设缺口时：在 DD §1.3 记轻量 ADR → 回流更新 HLD（勿仅在详设内偷偷改边界）。
