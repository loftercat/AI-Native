# 领域词表：恋爱预见（love-forecast）

> 与 [system-landscape.md](../architecture/system-landscape.md) 对齐。
> Story / HLD / 详设须与本表对齐；新术语在首现 Story 或 HLD 中定义后回写本表。

---

## 一、关系与档案

| 术语 | 英文 | 定义 |
|------|------|------|
| 关系档案 | Relationship Profile | 一段亲密关系 = 一个对象。包含对方代号、关系类型、关系状态、行为观察集、历史会话。一个账号最多 3 个 |
| 关系对象 | Partner | 用户的另一半。非注册用户，只以沟通记录与行为观察集的形式存在，不登录、不可见 |
| 关系类型 | Relationship Type | 恋人 / 暧昧 / 夫妻 / 前任复合 四类枚举 |
| 关系状态 | Relationship Status | 甜蜜期 / 平稳 / 冷战 / 频繁争吵 / 濒临破裂 五类枚举 |

## 二、观察与样本

| 术语 | 英文 | 定义 |
|------|------|------|
| 行为观察集 | Behavior Observation Set | 对外称「人格画像」。从沟通记录中**可复算**的行为计数与原句切片：消息节奏、话轮结构、回应性行为、词频。**不含**特质分数、类型标签、需求推断 |
| 沟通样本 | Conversation Sample | 用户导入的原始聊天文本；导入为可选能力，不阻断首次使用 |
| 派生量 | Derived Metric | 由样本纯代码计算的量：延迟分位数、长度分布、时段占比、每百词命中数。可复算，不含推断 |
| 样本充分性 | Sample Sufficiency | A 级（≥2 周且 ≥300 条、≥3 次事件、双边）可出趋势；B 级只出描述与计数；C 级只出当次会话分布 |
| 编码信度 | Coding Reliability | 分类判断进入输出前的门槛：Cohen's κ ≥ .70；未达标只出原句与「疑似」 |

## 三、情境与建议

| 术语 | 英文 | 定义 |
|------|------|------|
| 情境 | Situation | 一次求助的上下文：发生了什么、对方最后说了什么、想达到什么 |
| 现场描述模式 | On-the-spot Mode | 无历史记录时的主要模式：用户自然语言描述，系统追问最多 5 轮后直接给建议 |
| 诉求类型 | Intent Type | 和好 / 表达不满 / 拒绝 / 撒娇 / 道歉 / 试探态度 / 结束对话 |
| 行为构件 | Behavior Component | 建议的原料：复述情绪、认可、具体行动承诺、开放式提问、边界表达、事实陈述、具体请求 |
| 三档策略 | Three-tier Strategy | 稳妥（认可 + 承诺）/ 共情（复述情绪 + 认可 + 开放提问）/ 直给（事实 + 边界 + 请求）。**按风险与目标取舍划分，不按语气软硬** |
| 回复建议 | Reply Suggestion | 一条可复制的话术，必须带四要素：依据、适用前提、风险、失效条件 |
| 依据 | Basis | 指向具体观察条目或情境原话的引用；指不回去的建议直接丢弃 |
| 失效条件 | Fails When | 该档建议在什么对方状态下会适得其反；必须与建议同屏展示 |

## 四、对话与记忆

| 术语 | 英文 | 定义 |
|------|------|------|
| 模拟对话 | Simulation | AI 以对方口吻回应，供用户演练。单次 ≤10 轮，独立上下文，不进入建议生成 |
| 假设性解读 | Hypothetical Reading | 模拟每轮附的 1–3 种可能解读，全部标注为假设，不给单一「真实想法」 |
| 档案记忆 | Profile Memory | 跨会话复用的结构化条目：观察、建议、反馈、修正。**不存整段对话** |
| 采纳反馈 | Adoption Feedback | 用户是否采纳某条建议；事后回填的对方真实反应是唯一的效果标签 |

## 五、边界与安全

| 术语 | 英文 | 定义 |
|------|------|------|
| 越界校验 | Boundary Guard | 规则层（禁用词、长度、字段完整性）+ 模型层（像不像本人、是否断言动机）的双重校验 |
| 安全转介 | Safety Referral | 识别到自伤、他伤、暴力、胁迫时中止建议并给出专业求助资源；不做风险分级 |
| 不可推断声明 | Cannot-Infer Statement | 每条结论必须附带的边界说明，写明「不能说明什么」 |
| 证据强度 | Evidence Strength | 理论层面的支持程度：强 / 中 / 弱 / 争 / 不适用。与「本样本充分性」是两个独立评级 |

## 六、状态机速查

**会话状态**：`草稿 → 已生成 → 已采纳 / 未采纳 → 已回填`

**关系档案状态**：`启用 → 归档`（归档后不可新建会话，数据保留）；`任意 → 已删除`（级联物理删除）

**单次建议生成**：`情境解析 → 策略合成 → 话术生成 → 校验 → 输出`；任一步失败则整次重生成，不降级放行
