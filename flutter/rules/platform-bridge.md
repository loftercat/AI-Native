# Android / iOS 与原生 SDK

Dart 定义抽象，平台实现分别落入 Android Kotlin 和 iOS Swift 的插件或宿主适配层。沿用已有插件时核对两个平台实现与版本。画像记录最低系统、SDK 初始化、权限声明、隐私与功能支持范围。

DD 为每个能力列出方法或事件名、参数类型/单位/可空性、请求 ID、成功/取消/拒绝/不可用/超时及资源释放。MethodChannel 适合请求响应，EventChannel 适合持续事件；复杂模型可用项目认可的类型化绑定。两端返回同一 Dart 结果类型。重入与迟到回调按请求/会话标识判重；平台回调按 SDK 线程约定切换，单个调用只完成一次。

| 能力 | 实现约束 | 双端验收 |
|---|---|---|
| 地图 | 权限按需申请，手动选点可降级；记录坐标系；绑定地图视图创建、暂停、销毁与事件取消 | 拒绝定位、手势、后台恢复、连续进出 |
| 支付 | 发起前保存业务单号；SDK 返回或 App Link / Universal Link 唤醒后查服务端订单；确认中允许恢复 | 成功、用户取消、返回两次、杀进程重启；仅服务端确认可标记已支付 |
| IM | 会话级连接与订阅；重连按消息标识去重、补拉缺口；退出解绑设备 | 断线重连、乱序、换号、推送点击与前台接收重合 |

Android 核对 Manifest、权限拒绝及系统返回；iOS 核对 Info.plist 用途说明、entitlements、返回手势。两端测试授权、拒绝、从设置页返回。深链校验 scheme、host、路径、账号权限；私密参数不进日志。第三方 SDK 按产品隐私选择初始化。后续其他平台通过能力接口扩展，按本卡目标平台记录支持范围。
