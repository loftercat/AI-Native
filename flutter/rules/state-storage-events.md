# 状态共享、存储与事件

| 需要 | 负责人和范围 | 生命周期 / 验收 |
|---|---|---|
| 展开、输入焦点 | Widget 局部状态 | 随页面释放 |
| 列表、分页、提交 | 页面 Controller | 区分首载、刷新、空态、加载更多、提交中；旧结果不得覆盖新查询 |
| 购物车、用户资料 | 会话范围内 Repository + 可观察状态 | 多页读取同一数据源；换号销毁缓存、订阅和未完成操作 |
| 主题、语言 | 应用配置 + 轻量 KV | 有默认值、兼容旧 key；不存凭据或待同步订单 |
| 少量可续期凭据 | 平台安全存储 | iOS Keychain、Android Keystore 支持的存储；验证登出、锁屏、备份恢复 |
| 结构化数据、离线队列 | 按账号分区的数据库 | 为模型升级提供迁移并用旧库验证；需要同时成功的写入放同一事务 |
| 附件、可重建资源 | 私有文件或缓存目录 | 定义容量、淘汰、访问和备份。清缓存保留未上传的原件 |

DD 写明状态权威来源、作用域、谁能写、订阅何时结束。派生值由已有状态计算。简单回调用于父子交互；跨页观察 Repository，瞬时通知使用带类型的 Stream/回调。SnackBar、导航等副作用按一次动作消费，Widget 重建不会重放。广播没有订阅者时可能丢失，支付结果、未读数等可重新查询或持久化。

缓存定义过期条件、更新来源和失败展示。支持离线写入时定义本地待同步记录、稳定操作 ID、幂等提交、冲突处理和删除同步；账号切换时隔离队列。时间戳只在统一时区及协议精度下比较。

推送入口统一解析，按消息 ID 去重，校验目标账号及路由参数后读取权威数据；处理前台、后台点击和冷启动，登录完成后恢复一次。账号变更解绑推送标识，处理 token 轮换。后台回调与 UI 可能运行在不同 isolate，持久化必要输入，回到前台重读。
